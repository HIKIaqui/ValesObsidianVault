# Armas

Armas e ferramentas indicam a Perícia usada e seus parâmetros de combate.

## Parâmetros

| Campo | Função |
| --- | --- |
| Perícia | Define o teste: Porrada para combate bruto, Técnica para combate preciso ou Mira para distância e arremesso. |
| Empunhadura | Define se utiliza uma ou duas mãos. |
| Dano | Indica quantidade e tipo dos dados de dano. |
| Precisão | Acrescenta ou remove dados do teste de acerto. |
| Crítico | Valor natural necessário para ativar crítico. |
| Alcance | Níveis de Distância que o ataque pode atingir. |
| Peso | Contribuição para a carga do personagem. |

## Empunhadura

Usar um equipamento com uma mão aplica **-2 Precisão**. Com duas mãos, essa penalidade não é aplicada.

- **1M:** pode ser usado com uma mão ou duas.
- **2M:** deve ser usado com duas mãos. Constituição 3 permite usar com uma mão, com a penalidade de -2 Precisão e -1 Agilidade para cada ponto de Peso acima de 1 da arma mais pesada empunhada.
- **OB2M:** exige duas mãos independentemente da força, como arcos.

## Armas de Fogo

- **Capacidade:** disparos disponíveis antes de recarregar.
- **Integridade:** valor no dado de acerto que faz a arma emperrar ou falhar, funcionando como um crítico invertido.
