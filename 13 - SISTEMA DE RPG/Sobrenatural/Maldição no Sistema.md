# Maldição no Sistema

Maldições são negociações com entidades ocultas. Concedem poderes, mas também cobram algo de valor igual ou maior.

Para criar uma Maldição, é necessário desejar profundamente ou declarar o desejo em voz alta e com convicção, buscando convencer as entidades.

A força fundamental relacionada está em [[Maldição]]. Para conjurações contínuas por Malcor, consulte [[Runas de Conjuração]].
