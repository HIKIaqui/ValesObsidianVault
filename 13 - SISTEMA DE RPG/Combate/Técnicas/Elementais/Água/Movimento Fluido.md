# Movimento Fluido

**Elemental:** Água

2 PE | Acrobacia | O usuário pode se mover +1 nível de distância, mas apenas para recuar | Se estiver molhado, recebe +2 + (Bônus de Vontade / 2) [[Esquiva]] até o final do turno. Caso contrário, fica [[Molhado]]. | O usuário se move de forma fluida, desviando ataques como se deixasse seu corpo “escapar” por entre as forças do inimigo.
