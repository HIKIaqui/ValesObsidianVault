# Distâncias

O deslocamento não é medido em metros, mas em **Níveis de Distância**. Cada nível representa um intervalo aproximado e narrativo entre personagens, objetos e criaturas.

São zonas relativas: a posição de cada personagem é definida pela distância em relação a outro.

| Distância | Nível |
| --- | ---: |
| Corpo a Corpo | 0 |
| Curta Distância | 1 |
| Média Distância | 2 |
| Longa Distância | 3 |
| Muito Distante | 4 |

O alcance de um ataque indica quais distâncias ele pode atingir. O movimento está em [[Deslocamento]].
